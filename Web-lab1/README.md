# Turkey Travel Guide - Assignment 1

## Theme
This website is a travel guide about popular tourist destinations in Turkey (Istanbul, Cappadocia, Pamukkale, Antalya, and Trabzon). The goal is to provide basic travel information using HTML5

## File Organization
- `index.html` - Home page with site overview, articles and navigation.
- `about.html` - About page with project details, quotes and semantic tags.
- `services.html` - Destinations page with a structured comparison table.
- `contact.html` - Contact page with a travel inquiry form.
- `assets/` - Folder containing image files used across the website.
- `README.md` - Documentation of the project.

## Challenges Faced
- Building layout and structure using only semantic HTML elements.
- Correctly pairing form inputs with their corresponding labels using the `for` and `id` attributes.
- Remembering not to close self-closing tags like `<img>` and organizing table headers, bodies, and footers properly.
